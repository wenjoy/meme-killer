## 一句话背景

这个项目的核心难点不是「算出一个分」，而是**不要自信地算错**。
所有看起来啰嗦的写法（三层部署者来源、单位纪律、未知 ≠ 安全、
口径修正）都是为了让错误的结论无法产生。
